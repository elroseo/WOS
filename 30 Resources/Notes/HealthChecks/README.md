# Health Checks

## Start here

- [[Health Check 101]]: what a Health Check should answer and the end-to-end workflow.
- [[Health Check Runbook]]: repeatable technical evidence collection in this folder.
- [[GHES API Workload Analysis Method]]: reusable API capacity, burst, actor, controller, and endpoint analysis.
- [[Health Check Structure and Review Reference]]: report structure, evidence language, and pre-review checks.
- [[Peer Summary and Recommendation Patterns]]: techniques from strong Health Check authors, common recommendations, and drafting prompts.

## Suggested workflow

1. Read [[Health Check 101]] to confirm purpose and scope.
2. Use [[Health Check Runbook]] to collect and validate evidence.
3. Use [[GHES API Workload Analysis Method]] when API pressure, Unicorn queueing, or concentrated automation is in scope.
4. Use [[Peer Summary and Recommendation Patterns]] to identify customer-specific themes and actions.
5. Draft and review with [[Health Check Structure and Review Reference]].
