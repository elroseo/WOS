# How I Use WOS-PARA

Primarily, my work Obsidian vault is a second-brain setup, somewhat Karpathy-esque if you are familiar with that approach. I call it **WOS-PARA**, short for **Work Operating System using PARA**.

I capture learned information, meeting notes, customer context, tasks, troubleshooting methods, and reusable references in one place. Over time, that creates a searchable and relational knowledge base where I can connect current work to previous conversations, investigations, and lessons.

## How it is organized

I use **PARA** to organize information by actionability:

- **Projects** are active outcomes with a finish line.
- **Areas** are ongoing responsibilities and standards.
- **Resources** are reusable knowledge, methods, and reference material.
- **Archives** contain inactive information that is still worth retaining.
- **Inbox** is temporary capture for information that has not been classified yet.

## How I find and connect information

- **QMD** provides keyword and semantic search across the vault.
- **Obsidian links** connect related people, customers, meetings, methods, and technical topics.
- **Tasks** stay inside the notes that provide their context, while [[Task Dashboard - Filtered]] collects them into one view.
- **Copilot CLI** helps retrieve, summarize, structure, and update the vault.
- **Graphify** can map relationships across the knowledge base.
- **Git** provides local history and private backup.

## The goal

The goal is not simply to store notes. It is to turn everyday work into reusable context and make it easier to find what I know when I need it.

Information captured during work can mature over time:

1. A meeting, investigation, or task produces raw context.
2. Related notes and links make that context discoverable.
3. Repeated lessons become reusable methods, queries, or runbooks.
4. Those resources improve future work without requiring me to start from scratch.

## Short description

> WOS-PARA is my work-focused second brain in Obsidian. I use PARA to organize information by actionability, QMD to search it semantically, and links to connect people, customers, meetings, tasks, and technical knowledge. The aim is to turn everyday work into reusable context that becomes more valuable over time.
