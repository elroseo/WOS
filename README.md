# WOS PARA

This is a reconstructed copy of the WOS Obsidian vault. It combines:

- PARA for organizing information by actionability
- Obsidian Markdown, Bases, Canvas, and CLI agent skills
- QMD for local keyword and semantic retrieval
- Graphify for relationship and knowledge-graph analysis
- Git for local history and private GitHub backup

## Structure

- `00 Inbox/`: captures awaiting classification
- `10 Projects/`: active outcomes with a completion condition
- `20 Areas/`: ongoing responsibilities and standards
- `30 Resources/`: reusable reference material
- `40 Archives/`: inactive projects, areas, and resources
- `90 System/`: templates, generated views, and vault documentation

See `PARA Guide.md` for classification and review rules.

## Tooling

QMD and Graphify are generated indexes, not sources of truth. Markdown and other open-format vault files remain authoritative. Generated indexes and models should not be committed.

This repository starts with fresh local Git history. Add a private GitHub remote only after checking the copied content and repository visibility.
